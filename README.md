# Kinetik-AeroFasad
Proyek kinetik ini berfokus pada transformasi bidang datar menjadi fasad 3D bergerak. Menggunakan grid modul segitiga, setiap unit melipat secara presisi untuk membentuk piramida (tetrahedron). Rangkaian gerak mekanis ini memicu gelombang kinetik yang dinamis—dari riak sentuhan hingga aliran ombak—membuat arsitektur seolah hidup dan bernapas.
